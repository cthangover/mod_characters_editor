# Characters Editor — フォームで MOD のキャラクターを編集する

Characters Editor は、ゲームの実行中に MOD のキャラクターを編集します: MOD の各言語での名前、肖像、RPG マップの歩行グラフィック、戦闘の数値、勧誘の確率、バトルアクション。**保存**は MOD のファイルを書き込み、ゲームはすぐに変更を使います。

ツールボックス（ツールバーのハンマー）から**キャラクター**として開きます。

## 編集と、ゲームの中での結果

RPG Plus では、村の英雄は MOD `rpg_demo_game` のキャラクター `rpg_hero` です。上でその MOD を選び、**勇者**を選び、新しい英語名を入力して**保存**（Ctrl+S）を押します:

## フォーム

- **Id** — キャラクターの id。シナリオ、パーティ、バトル、マップがこれで見つけます。
- **名前** — 翻訳キーと、MOD の言語ごとの行。
- **肖像** — カードやパネルの画像。**…** で選ぶためのグリッドが開きます。
- **キャラチップ（RPG）** — RPG マップ上の歩行グラフィック（3 コマ × 4 方向）。RPG マップエディターは、配置のときにキャラチップ付きのキャラクターを提示します。
- **レベル**、**体力**、**攻撃**、**防御**、**行動ポイント**、**経験値** — キャラクターの戦闘の数値。
- **勧誘の確率** — 0〜100: 倒したあとにキャラクターを迎える確率（Recruiting を参照）。
- **行動パターン**と**アクション** — キャラクターがどう戦うか、どんなバトルアクションを持つか。
- **他の MOD のフィールド** — 他の MOD がスキーマでキャラクターに付けるフィールド（たとえば Stats Engine のクラス、ステータス、特性）は専用セクションに現れます。
- **その他のフィールド** — キャラクターの JSON の残り。JSON として編集され、そのまま保たれます。

ツールバー: **新規**（Ctrl+N）、**コピー**（Ctrl+D）、**削除**、**元に戻す**/**やり直す**（Ctrl+Z / Ctrl+Y）、**保存** — 変更されたファイルだけが書き込まれ、テキストは MOD のローカライズファイルに入ります。

## どのキャラクターを編集できるか

一覧には、選んだ MOD 自身のファイルにあるキャラクターが入ります。提示されるのは、フォルダーとしてインストールされた MOD だけです。他の MOD のキャラクターは一覧になく、そのファイルが書かれることもありません。変えるには、自分の MOD で同じ id を所有者への依存関係付きで配るか、パッチでフィールドを足します。

## うまくいかないとき

1. **体力や攻撃を変えても効かない。** ゲームはステータスから数値を計算します。RPG Plus がパーティに対してしているように。
2. **キャラクターが RPG マップエディターの「キャラクター」タブにいない。** このタブは戦闘ステータスのあるキャラクターを一覧します。どんなグラフィックでも「Appearance」タブから配置できます。
3. **MOD の一覧が空。** パッケージ済みの MOD は編集できません。
